# 四项可靠性修复

日期：2026-10-11。本轮只修复现有功能的校验、失败状态、凭证撤销与启动可靠性，没有增加 Agent 工具或修改业务表结构。

## 排课写入

- 新增、修改仅接受 `1-2节 / 3-4节 / 5-6节 / 7-8节`，非法值返回业务码 400。
- 同一学生、同一天、同一节次已被占用时返回 409：`该学生 YYYY-MM-DD X-X节 已有课表安排，请调整日期或节次`。修改排除当前记录自身；失败不修改原记录。
- 每次写入先锁学生父行，再通过当前锁定读取检查冲突。跨学生调整按 ID 顺序锁定，避免两个业务请求同时写入空格子。不依赖修改表结构。
- `teacher / start_week / end_week` 接入原排课接口与管理员表单。新建省略字段仍默认教师为空、1 至 `TOTAL_WEEKS` 周；更新省略保持原值，教师显式 `null` 可清空。
- 周次越界、非整数、起始周晚于结束周返回 400。列表保留所有原字段；MCP 原课表字典字段不变。学生只能查询本人的过滤规则不变。
- 前端标准节次与周数读取已有周接口；保存失败保留表单，校验阶段即锁定提交，避免快速重复请求。

## 首页失败状态

- 课表网络失败、业务非 200、返回数据格式错误均显示错误与重试，不显示“今天没有课”。只有成功取得当日数据且课程为空时显示该空状态。
- 文本计划与管理员各统计独立处理失败。统计未知时显示 `—`，知识库读取失败不会出现“知识库还没有文档”。成功空文档列表仍保留原引导。
- 明日预告失败不抹掉今天的课表；第 20 周周日不请求第 21 周；学期外明确提示。
- 现有截止提醒、首页卡片、快捷入口、文本学习计划操作均保留。

## 账号与凭证

- 注册、登录、管理员新增账号共用账号非空、去首尾空白、最多 50 字的校验。密码非空且 UTF-8 编码最多 72 字节，非法输入返回业务码 400，不交给 bcrypt 抛服务器异常。
- 密码不自动去空白、不截断；`aaa/123`、`bbb/123`、`admin/admin` 等现有登录方式不变。注册和新增账号的姓名仍可省略，默认使用账号。
- 新 JWT 附带由服务器密钥与当前密码哈希计算的 HMAC 指纹 `pwdv`，不包含密码或 bcrypt 哈希。HTTP 与 MCP 都对照当前密码状态校验。
- 修改密码后所有旧凭证立即返回 401；新密码登录正常。修改普通资料不会撤销登录，其他账号不受影响。重新设置为曾经用过的密码也会生成新的 bcrypt 哈希，不恢复旧凭证。
- **更新后请重启 FastAPI 与 MCP，再重新登录一次。** 旧格式凭证没有 `pwdv`，会被拒绝。无需修改 `.env`、轮换密钥或迁移 `users` 表。

## 启动与回收

- FastAPI 校验 OpenAPI，MCP 进行握手和工具发现，前端校验实际页面；所有服务就绪后才报告“启动完成”。这些就绪检查不调用模型、embedding 或业务工具。
- 任一启动进程退出、就绪超时或最终确认失效都非零退出；只回收本轮启动的进程组及其 reload/npm 子进程，已有服务继续运行。
- 既有 `--check`、`--no-frontend` 与 `--restart-mcp` 保留。显式重启 MCP 前须确认当前 8001 服务提供本项目工具，否则拒绝关闭。
- `STARTUP_TIMEOUT_SECONDS` 可通过启动命令环境指定，范围 1～120，默认 30。日志写入权限受限的临时目录，终端给出路径；不回显可能包含内部配置的异常原文。
- README 的前端测试命令遇任一文件失败立即退出，不再只取最后一个文件的结果。
